## 簡單QR掃描 v1.0.0-debug.1

這是提供功能測試使用的 **Debug Pre-release 版本**，不是正式發行版本，也不適合提交至 Google Play。

### 版本內容

- 相機即時 QR Code 掃描與手電筒
- 從圖片辨識 QR Code
- 支援網址、Wi-Fi、電話、Email、簡訊、位置、聯絡人、行事曆與文字
- 掃描結果複製、分享及對應系統操作
- 本機掃描紀錄管理
- 六種可即時切換的活潑主題色彩
- 明亮模式與深色模式即時切換
- 系統狀態列與底部導覽列同步明暗模式
- 全新雙層 Adaptive App Icon

- 檔案類型：Android Debug APK
- 簽章類型：Android Debug 簽章
- 最低系統：Android 8.0（API 26）
